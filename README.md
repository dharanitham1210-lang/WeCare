# WeCare
AI elderly care assistance for dementia patients



Dementia patients often face:

Memory loss and repeated questioning
Disorientation and confusion
Anxiety and emotional distress
Difficulty remembering people, routines and important events
Continuous dependence on caregivers

At the same time, caregivers cannot monitor and support the patient 24/7.

Our Solution — WECARE

A memory-safe, voice-first AI companion that supports dementia patients while keeping caregivers informed and in control.

Core idea:

Patient → AI Companion → Caregiver → Human Intervention

Personalized Verified Memory Architecture
Voice-based AI interaction
Safe, policy-controlled responses
Distress/risk signal detection
Real-time caregiver alerts
Guardian monitoring & memory approval
